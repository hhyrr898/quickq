### 为什么 quickq 在我的 Android 手机上连不上或者连接不稳定？

这是最常见的问题了，特别是在出差或换了工作地点后。连接问题可能涉及好几个方面。

1.  **检查网络环境：** 确保你的手机网络连接正常，无论是 Wi-Fi 还是移动数据。可以尝试打开其他应用看看能否正常上网。
2.  **切换节点：** quickq 提供很多不同的服务器节点。有时候某个节点可能因为使用人数过多或网络波动而变慢或断开。
    *   打开 quickq 应用。
    *   进入主界面，点击当前的连接节点，会弹出一个节点列表。
    *   从列表中选择一个不同的节点，比如尝试一些标注为“推荐”或距离你较近的节点。
    *   点击连接按钮，看看是否能成功连接。
3.  **清除应用缓存：** 长期使用可能会积累一些缓存数据，影响应用运行。
    *   前往手机的“设置” > “应用管理”（或类似名称）。
    *   找到 quickq 应用，点击进入。
    *   选择“存储与缓存”，然后点击“清除缓存”。注意，不要点击“清除数据”，那会删除你的登录信息。
4.  **重启手机或应用：** 简单的重启操作往往能解决很多玄学问题。先退出 quickq，然后重启手机，再重新打开 quickq 尝试连接。

### 我出差在外，换了手机号，如何确保 quickq 账号安全和正常使用？

远程办公或旅行时，手机号、设备可能会变动，管理好 quickq 账号很重要，特别是涉及到登录和订阅。

### 为什么 quickq 连接成功了，但是上网速度还是特别慢？

连接上了不代表速度就一定快。我在测试 quickq Android 客户端 2.1.0 版本时，也遇到过连接成功但刷网页很慢的情况。这通常和网络状况和节点选择有关。

1.  **切换节点到优质线路：** quickq 会根据节点负载和地理位置提供不同的线路。有些节点可能当前负载较高，或者与你当前所在位置的网络运营商不兼容。
    *   打开 quickq 应用，在节点列表中寻找“推荐”或“负载低”的节点。
    *   可以多尝试几个不同地区的节点，比如你人在南方，可以试试北方的节点，反之亦然，有时候会有意想不到的效果。

2.  **检查本地网络：** 有时候问题不在 quickq，而是你自己的 Wi-Fi 或移动数据本身就不给力。
    *   可以尝试断开 quickq 连接，直接用手机网络测速，看看基础网速如何。
    *   如果是 Wi-Fi，尝试重启路由器。
3.  **避开高峰期：** 晚上或特定时段，大量用户同时在线，可能导致整体网络拥堵。如果不是紧急任务，可以尝试错峰使用。

### quickq Android 客户端支持应用分流吗？怎么设置？

有些朋友可能只想让特定应用走 quickq 线路，其他应用走直连，这样可以节省流量或提高特定应用的访问速度。quickq Android 客户端通常都支持这种“分应用代理”或“智能分流”功能。

1.  **进入分流设置：**
    *   打开 quickq 应用，进入“设置”或“我的”页面。
    *   寻找“分应用代理”、“应用分流”或“智能分流”等类似名称的选项。
2.  **选择分流模式：** 通常会有两种模式：
    *   **全局代理：** 所有应用都走 quickq 线路（默认模式）。
    *   **分应用代理：** 你可以手动选择哪些应用走 quickq 线路，哪些不走。
3.  **自定义应用列表：**
    *   选择“分应用代理”模式后，系统会列出你手机上安装的所有应用。
    *   勾选你希望通过 quickq 访问的应用（例如，某些工作应用或国外社交媒体）。
    *   取消勾选那些你希望直连的应用（例如，国内视频应用或银行App）。
4.  **保存设置并连接：** 设置完成后，保存更改并重新连接 quickq。这样，只有你选中的应用会通过 quickq 传输数据。

这个功能在远程办公时非常实用，比如你只想让公司的特定应用走代理，而其他生活应用保持直连。
