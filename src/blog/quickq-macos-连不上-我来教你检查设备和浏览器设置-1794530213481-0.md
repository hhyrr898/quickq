### **实操步骤：设备与浏览器排查**

很多时候，quickq连不上或者用着不顺，不一定是它自己的问题，可能是你设备或浏览器的设置“捣乱”了。我一般会先从这几个地方入手检查：

1.  **检查 macOS 网络设置（代理与 DNS）**
    *   **步骤一：确认系统代理设置**。
        *   打开“系统设置” -> “网络” -> 选中你正在使用的网络（例如 Wi-Fi） -> 点击“详细信息”。
        *   在弹出的窗口中选择“代理”，检查“自动代理配置”或“网页代理 (HTTP)”和“安全网页代理 (HTTPS)”是否被quickq正确设置。有时候其他应用或VPN可能会修改这些设置。如果quickq客户端正在运行，并且你选择了“全局模式”，这里通常会有代理设置。如果你发现有不认识的代理设置，可以尝试关闭或删除，然后重启quickq再试。
        *   **小贴士：** 如果你对系统代理设置不熟悉，可以尝试在quickq客户端中切换一下“模式”，比如从“全局”切换到“分流”再切回来，让它重新配置一下代理。

2.  **检查浏览器代理设置（针对特定浏览器）**
    *   **步骤二：检查浏览器代理设置**。
        *   大多数浏览器会遵循系统代理设置，但也有例外，尤其是Chrome、Firefox这类浏览器，它们有时候会有自己的代理设置或者扩展程序在影响网络。例如，如果你的Chrome安装了其他代理插件，可能会和quickq的代理冲突。
        *   对于Chrome，你可以去“设置” -> “系统” -> “打开您计算机的代理设置”确认。如果安装了代理扩展，可以尝试暂时禁用这些扩展，或者确保它们的优先级低于quickq。
        *   如果只在某个浏览器出现问题，不妨换个浏览器试试看，能快速判断问题是出在浏览器本身还是系统层面。

3.  **检查防火墙与安全软件**
    *   **步骤三：确认防火墙和安全软件未阻拦quickq**。
        *   macOS自带的防火墙（“系统设置” -> “网络” -> “防火墙”）默认情况下不会阻拦常用应用，但如果你安装了第三方安全软件、杀毒软件或者网络监控工具，它们可能会误判并阻拦quickq的网络连接。
        *   你可以尝试暂时关闭这些第三方软件（注意：请确保你的网络环境安全），然后再次尝试连接quickq。如果连接成功，那么问题很可能出在安全软件上，你需要将quickq添加到其白名单或信任列表中。

这些简单的检查步骤，往往能解决大部分连接障碍。有时候，一个小小的设置就能让你的quickq重获新生。如果你想了解更多macOS客户端的安装细节，可以看看这篇 [quickq macOS 安装教程](/blog/quickq-macos-install-steps/)。

## 常见问题

### quickq 为什么连不上？

这可能是最常见的问题了。除了上面提到的设备和浏览器设置，还有可能是以下原因：

*   **网络环境问题：** 你的网络本身就存在不稳定或受限的情况。
*   **节点故障：** 当前连接的quickq节点可能出现故障或负载过高，尝试切换到其他节点。
*   **账号问题：** 检查你的quickq账号是否过期，或者是否存在多设备同时登录导致冲突（特别是如果你的套餐有限制）。
*   **客户端版本过旧：** 确保你的quickq客户端是最新版本。旧版本可能存在已知bug或无法适应新的网络环境。

### 连上后速度慢怎么办？

*   **更换节点：** 这是最直接有效的方法。尝试切换到不同地区或线路的节点，寻找最适合你当前网络环境的节点。
*   **检查本地网络：** 确保你自己的Wi-Fi或有线网络带宽充足且稳定。
*   **关闭无关应用：** 占用大量网络带宽的应用（如下载工具、视频流媒体）可能会影响quickq的速度。
*   **清除浏览器缓存：** 有时候浏览器缓存过多也会影响网页加载速度。

### 怎么切换节点？

在quickq客户端主界面，通常会有一个“选择节点”或“线路选择”的选项。点击进去，你可以看到不同的国家、地区或线路列表。选择一个你想要的节点，然后点击连接即可。我个人建议多尝试几个，找到延迟最低、速度最快的。

### macOS 更新后 quickq 不能用了？

macOS系统的大版本更新（比如从Sonoma升级到下一个大版本）有时会改变系统底层的一些网络API或安全策略，这可能导致旧版本的quickq客户端无法正常工作。遇到这种情况，首先尝试将quickq客户端更新到最新版本。如果更新后依然无法解决，可以尝试卸载并重新安装quickq，或者检查quickq官网是否有针对新macOS版本的兼容性说明或补丁。有时候，重新授权QuickQ的网络权限也能解决问题。
