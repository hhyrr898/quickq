## 常见问题

在使用 quickq macOS 客户端过程中，我遇到过一些问题，也总结了一些常见的解决办法，希望能帮到你。

### Q1: quickq macOS 客户端连不上怎么办？

1.  **检查网络连接：** 确保你的 Mac 本身网络是正常的，能访问国内网站。
2.  **更换线路：** 尝试切换到客户端提供的其他线路，有时候某个线路可能会暂时拥堵或维护。
3.  **重启客户端：** 关闭 quickq 客户端，稍等几秒钟后重新打开并连接。
4.  **重启电脑：** 这是最简单粗暴但有时很有效的方法，可以清除系统缓存和网络状态。
5.  **检查系统设置：** 确认没有其他代理软件或防火墙阻止 quickq 的网络连接。

### Q2: quickq 连接成功了，但上网速度很慢，或者卡顿怎么办？

1.  **更换线路：** 优先尝试连接离你物理位置较近的线路，或者标注“负载低”的线路。
2.  **检查本地网络：** 确保你的路由器和宽带服务没有问题，可以尝试重启路由器。
3.  **关闭占用带宽的应用：** 检查是否有其他应用正在下载大文件或进行高清视频直播，它们会占用大量带宽。
4.  **清理浏览器缓存：** 浏览器缓存过多有时也会影响加载速度。

### Q3: 为什么 quickq 连上了，但在浏览器里还是打不开某些网站？

1.  **清空浏览器缓存和 Cookies：** 很多时候，这是最有效的办法。旧的缓存可能会导致访问失败。
2.  **尝试浏览器的隐身模式/隐私模式：** 这样可以排除浏览器插件或扩展程序的影响。
3.  **检查浏览器代理设置：** 确认你的浏览器没有被其他工具设置了固定的代理，与 quickq 冲突。
4.  **更换浏览器：** 如果Chrome不行，可以试试Safari或Firefox，看是否是浏览器兼容性问题。
5.  **检查 quickq 设置：** 确认 quickq 是全局代理模式，而非仅代理部分应用。
